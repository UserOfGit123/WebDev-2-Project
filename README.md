# WebDev-2-Project
Smart Task Tracker

## Project Title
Smart Task Tracker - A DOM-Based Task Management Web App

---

## Project Description
Smart Task Tracker is a fully functional task management web application built using HTML, CSS, and Vanilla JavaScript. It allows users to add, edit, delete, search, filter, and sort tasks while maintaining persistent data using LocalStorage.

The application behaves like a real-world productivity tool and demonstrates strong understanding of DOM manipulation, event-driven programming, and client-side state handling.

---

## Problem Statement
Managing daily tasks using static lists or notes can be inefficient and unorganized. Users need an interactive and dynamic system to manage tasks, track priorities, and monitor deadlines.

This project solves that problem by providing a responsive and interactive task tracker that updates in real time and saves user data locally.

---

## Features Implemented

### Core Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed or undo
- LocalStorage persistence

### Advanced Features
- Task priorities (Low, Medium, High)
- Due date selection
- Overdue task highlighting
- Live search filtering
- Filter by:
  - All
  - Completed
  - Pending
- Sorting:
  - By due date
  - By priority
- Color-coded priority badges
- Clean and responsive UI

## Steps to Run the Project
1. Download or clone the repository
2. Ensure these files are present:
   - index.html
   - style.css
   - script.js
3. Open index.html in any modern browser
4. Start adding and managing tasks

No server or installation required.
